# 🚀 Vikramaditya Kumar - Full Stack Developer Portfolio

A modern, high-performance, and customizable developer portfolio built with responsive HTML5, CSS3 Custom Properties, and Vanilla JavaScript. Features dark/light themes, accent color switcher, live interactive portfolio customizer drawer, project filtering, and smooth animations.

---

## ✨ Features

- 🌓 **Dark & Light Mode:** Seamless toggle with user preference persistence.
- 🎨 **Multi-Theme Accent Switcher:** Choose between **Midnight Blue**, **Cyberpunk Purple**, **Emerald Green**, and **Sunset Amber**.
- 🛠️ **Real-Time Portfolio Builder Drawer:** Edit profile, skills, experience, and projects on the fly directly inside the browser with zero build tools required!
- 💾 **Data Export & Import:** Export your updated configuration as `portfolio-data.json` or download a self-contained HTML file.
- 💻 **Interactive Hero & Code Card:** Dynamic typing text animation and interactive floating developer object widget.
- 📂 **Filterable Projects Showcase:** Filter projects by category (`All`, `MERN Stack`, `Frontend`, `Full Stack`).
- ⚡ **Zero-Build Architecture:** Runs natively in any browser with zero npm dependencies or complex build steps.

## 🚀 How to Run Locally

Simply open `index.html` in your favorite web browser (Chrome, Edge, Firefox, Safari).

Or use any lightweight local server:
```bash
# Python 3
python -m http.server 3000

# or Node.js npx serve
npx serve .
```

## 🌐 Free Instant Deployment

### Option 1: Vercel (Recommended)
1. Push this folder to a GitHub repository.
2. Go to [vercel.com](https://vercel.com) and import your repo.
3. Keep default settings (Framework: *Other*) and click **Deploy**.

### Option 2: GitHub Pages
1. Push this directory to your GitHub repository (e.g. `vikram212v.github.io` or `portfolio`).
2. Go to **Settings > Pages > Build and deployment**.
3. Set Source to `Deploy from a branch` (Branch: `main` / `root`).
4. Click **Save**.
